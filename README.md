MVP - Machine Learning

Este projeto tem como objetivo principal analisar e classificar o perfil ofensivo dos times do Campeonato Brasileiro por meio de técnicas avançadas de machine learning. Utilizando um dataset completo com dados históricos das partidas do campeonato, buscamos identificar padrões de comportamento ofensivo entre as equipes, validando nossa abordagem através de métricas de acurácia dos algoritmos implementados.
